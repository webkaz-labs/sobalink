# 共通の画面ブランド

[English](README.en.md)

Web UI とネイティブコンパニオンで、色トークン、3 本バーのマーク、アイコン形状を共有します。既存の Web の色を基準にし、密度、配置、OS のアクセント色、高コントラスト対応は各 UI に残します。

- `palette.json` はライト・ダークの意味別の色です。Go は `Palette(dark)` で取得します。変更後は `web` で `npm run brand:generate` を実行します。`brand:check`、Web ビルド、テストは配布用 CSS の更新漏れを検出します。
- `icons.json` は既存 Web のパスです。React は直接読み込み、Go の `IconSVG(name)` は同じ 24×24、線幅 1.7 の SVG を返します。呼び出し側が `currentColor` の色を選びます。
- `mark.svg` は傾いた 3 本バーです。Web はアルファマスクと現在の主要色で表示し、同じアセットをファビコンにも読み込みます。Go の `MarkSVG()` は単体ファビコン用の既定色を除いたコピーを返し、呼び出し側の `currentColor` を継承します。`MarkOpaqueSVG()` は小さいトレイアイコン用に 3 本目も不透明にします。ネイティブ側で色を選びます。

これらのアセットは画面配置を規定せず、プラットフォームのアクセシビリティ設定を置き換えません。テストは配布用パレット、実際のコンポーネントのパス、アセットの派生形を確認します。実機・目視確認は別の受け入れ項目です。
