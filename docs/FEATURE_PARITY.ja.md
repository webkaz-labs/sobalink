# 機能対応と受入

[English](FEATURE_PARITY.en.md) · [文書一覧](README.md) · [検証記録](VERIFICATION.md)

**全機能の対応とリリース受入は、まだ確定していません。** 開発候補は未公開の `0.3.0-alpha.1` です。[v0.2.0-alpha.2](https://github.com/webkaz-labs/sobalink/releases/tag/v0.2.0-alpha.2) の正確なソース `0b0a13c4edd2924de149650152445507cc709da7` に含まれた機能を、固定のF01〜F56で追跡します。機能と旧コマンド・設定表記を区別します。現在の復元対象は、人向けCLI、確認付き探索、アプリ設定支援、任意の起動時接続・非公開プロキシ設定です。このソース対応表は、正確な公開コミットのCI・リリース記録の代わりにはなりません。

「実装済み」はソース上の操作経路を示し、実機や配布の受入を意味しません。ローカルのmock・設定・DOM試験、ネイティブCI、実Go本体のブラウザー実行、模擬データの見た目、実端末の試験は別の証拠です。実装済みの行も、最終統合ソースで影響する試験が必要です。
