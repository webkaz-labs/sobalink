# Tailnetへのサインイン

[English](SIGN_IN.en.md) · [起動](LIFECYCLE.ja.md) · [近くの端末との接続](CONNECTION_SETUP.ja.md)

本体を起動してTailnetを選びます。ローカル画面のネットワーク設定から、公式のサインインリンクを開けます。選択した中継先を利用するペア設定は別の手順で、このログインは使いません。

## サインイン方法を選ぶ

```sh
soba login --browser
soba login --qr
soba login --link
```

`--browser` は公式Tailscaleページを開いて完了を待ちます。`--qr` はこの端末だけでQRを生成し、他人に見えない端末に表示して、完了または端末承認待ちまで待機します。幅が不足する場合はQRを折り返さず、非公開リンクを案内します。`--link` は非公開リンクを明示的に出力して終了します。待機する場合は `--wait` も付けます。ブラウザーモードをリダイレクトした出力には非公開リンクを含めません。これらのリンクを共有したり、スクリーンショットに含めたりしないでください。

接続済み・管理者承認待ちの場合は認証をやり直しません。表示可能な既存リンクがあれば再利用し、`--refresh` を明示した場合に新しい手続きを要求します。`--timeout 5m` はローカルの待機時間で、ほかの正の期間も指定できます。リンク側の期限は変更・推定しません。Ctrl+Cは待機を取り消しますが、表示済みリンクの失効やノードの停止はしません。本体の停止には `soba stop` を使います。

通常の `soba login` は機械向けJSONを返します。`soba login --wait` は待機後の状態をJSONで返します。別プロフィールではコマンドの前に `--state-dir PATH` を指定します。

模擬試験でURL検証、繰り返し、承認待ち、取消、QRの画素と表示状態の復元を確認しています。スマートフォンでの読取り、実際の参加、IME・端末・フォントの組合せは実機の受入確認が必要です。

## 結果を読む

| 結果 | 次の操作 |
| --- | --- |
| 接続済み | `soba peers` を確認してサービスを選ぶ |
| 管理者の承認待ち | Tailnet 側の承認を完了する。不必要に認証をやり直さない |
| 待機中・タイムアウト | `soba status` を確認する。ローカルのタイムアウトはサインインリンクを取り消さない |
| Ctrl+C で待機を終了 | ノードとリンクは有効な場合がある。本体を止めるには `soba stop` |

Tailnet への登録と、ローカル Web 画面に入る一回限りのコードは別のサインインです。登録用リンクを公開の issue や共有ログへ貼り付けないでください。
