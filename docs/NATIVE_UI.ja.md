# 任意起動の Native UI（プレリリース）

[English](NATIVE_UI.en.md) · [配布と検証](DISTRIBUTION.md) · [CLIガイド](CLI_GUIDE.ja.md)

**`soba-native` は本体と別の、任意起動のデスクトップクライアントです。** Windows x64・macOS ARM64向けプレリリースの通常アーカイブに `bin/` 配下で追加する構成です。Linuxのアーカイブは変更しません。既存の `soba` CLI・Web UIは引き続き使えます。配布構成への対応は、公開成功や実機GUI動作の合格を意味しません。利用前に対象リリースの正確な検証記録を確認してください。

## まず通信しないデモを開く

対象リリースの署名・ビルド元の証明（来歴）・ファイルの照合値（ダイジェスト）を検証してから、展開したアーカイブの `bin` フォルダーをターミナルで開きます。バイナリの実行にGoは不要です。

Windows PowerShell:

```powershell
& .\soba-native.exe --demo --tray --locale auto
```

macOS（Apple Silicon）:

```sh
./soba-native --demo --tray --locale auto
```

`auto` はOSロケールが日本語なら日本語、それ以外は英語を選びます。明示する場合は `--locale ja` / `--locale en`、起動後は画面内の言語切替を使えます。デモの端末とやり取りは架空で、接続・メッセージ送信・ファイル転送は行いません。通常ウィンドウは `--tray` を外して開きます。

Packslipが通常のコマンドとして公開するのは引き続き `soba` だけです。インストールしてもNative UIは選択・起動されません。miseを使う場合は、**検証に合格したものと同じ正確なプレリリース指定**で `mise where` を実行し、そのインストール先の `bin/soba-native`（Windowsは `bin/soba-native.exe`）を明示的に実行します。バージョンを推測したり、古い試験キットで代用したりしないでください。Native UIには別の依存関係・ライセンス一覧があり、配布manifestと併せて確認します。

## プロファイルを明示して読み取る

本体の準備・起動は別途 [CLIガイド](CLI_GUIDE.ja.md) に従います。初回評価は既存の個人データを使わず、架空の表示名で新しい試験専用プロファイルを用意してください。以下の `TEST_PROFILE_DIRECTORY` をその絶対パスに置き換えます。

```sh
./soba-native --state-dir "TEST_PROFILE_DIRECTORY" --tray --locale auto
```

Windowsでは実行部分を `& .\soba-native.exe` に読み替え、引数は同じです。`--demo` と `--state-dir` はどちらか一つを指定し、暗黙のプロファイル選択はしません。本体と通信するモードも既定は読み取り専用です。「状態を取得」でユーザー専用の端末内通信（IPC）で本体から現在の状態を取得します。自動更新、本体の自動起動、設定変更はしません。IPC成功はネットワークの正常性や到達の証明ではなく、取得失敗時は古い表示を消します。

## 送信は明示フラグと内容確認の後に

```sh
./soba-native --state-dir "TEST_PROFILE_DIRECTORY" --tray --locale auto --enable-send
```

選択したプロファイルで確認付きのメッセージ・ファイル操作が有効になります。確定前に宛先と本文、またはファイル一覧・保存先を確認します。受信ファイルも保存先の確認と明示的な受入・辞退が必要です。信頼・一時停止の状態は変更せず、本体の既存の許可が適用されます。接続設定、各種設定、許可、更新、本体の管理は既存CLI・Web UIで扱います。

受付後にエラーになる場合があります。結果不明は未到達の証明ではありません。自動再送せず、再起動で操作ロックを回避しないでください。履歴・状態を更新して相手側でも確認します。要求受付と配送完了は別です。履歴は取得できた最新6件の表示で、全履歴ブラウザーではありません。

## 隠す・終了する

`--tray` ではメニューバー／通知領域のアイコンでパネルを開閉します。閉じる、「隠す」、入力欄などが処理しない Escape キーは非表示にする操作です。「UIを終了（本体は継続）」は `soba-native` だけを終了します。このクライアントは本体を起動・停止しません。下書きは非表示中も残りますが、UI終了で失われます。IMEやファイル選択を妨げないよう、フォーカスを失うだけでは隠れません。トレイ作成に失敗した場合は通常ウィンドウへ切り替わり、そのウィンドウを閉じるとUIが終了します。ログイン項目・サービス・自動起動は登録しません。

## 検証の範囲と安全上の注意

- 配布物の署名・来歴検証は配布の完全性とソースの確認です。Windowsの開発者・発行者署名、macOSのDeveloper ID署名・公証とは別です。ハッシュ一致だけでどちらも証明できません。
- OSや管理方針が実行を止めた場合は中止し、ブロックとして記録します。保護機能の無効化、隔離属性の除去、Gatekeeper・SmartScreenの回避、管理者権限での再実行はしません。
- 実ウィンドウ、トレイ、日本語入力（IME）、読み上げ、GPU・高DPI、休止復帰、長時間動作、実端末2台のネットワーク通信は実機受入が必要です。クロスビルド、画面を表示せず生成した画像、保護された端末内通信と共通処理の模擬データ試験で代替しません。
- 今回の統合ソースはPR #66を含みます。それを含まない過去の未署名PR #67試験キットは履歴であり、今回のリリース資産や新しいソースの合格証跡ではありません。最終バージョンや配布検証成功をこの文書では主張しません。
- 共有する結果は一般化し、架空データだけを使います。実際のアカウント名・端末名・パス・所属・利用状況など、個人や利用環境を特定・推測できるログ・画面・情報は配布しません。
