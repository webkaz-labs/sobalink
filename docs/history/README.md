過去の判断と、特定のソースで得られた結果を残す場所です。当時の未完了項目をそのまま現在の作業にしたり、過去の成功を後のソースの証拠にしたりしません。判断する前に、現在の検証記録とロードマップを確認してください。

## 履歴を保守する

- ソース ID、実行へのリンク、失敗、確認範囲、当時の未確認事項を保持します。古い記録を現在の製品の説明に書き換えません。
- 事実の誤りは訂正を明示します。後の実装や受入結果は、現在のガイド・検証記録・ロードマップへ記載します。
- 日本語と英語の記録をそろえます。共通の英語の実装記録は、文書一覧でその旨を示します。
- 以前の階層にある機能対応・計画ページは、公開済みのパスと見出しへのリンクを維持する案内です。本文はこのフォルダーだけで管理します。
- 別の文書を移す場合も、リポジトリ内のリンクと配布物内の相対リンクを確認します。過去の証拠を含むという理由だけで、現在の契約文書を履歴へ移しません。
