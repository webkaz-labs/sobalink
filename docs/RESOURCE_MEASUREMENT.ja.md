# 公開済みバイナリのリソース観測

[English](RESOURCE_MEASUREMENT.en.md) · [検証](VERIFICATION.md)

専用の `Published binary resource observation` workflow は、公開済み
`0.3.0-alpha.2` の Linux amd64 実行ファイルを測定します。対応するソースは
`00cc6a99809df77bf1754936ea7bf5ca4c5d0741` です。workflow の追加自体は測定結果では
ありません。完了した実行と集計 artifact を確認してから判断してください。
既存のクロスプラットフォーム CI とリリース条件は変更しません。

## 手順と同一性の確認

同じリポジトリ内の、測定用ファイルを変更する pull request で隔離された
GitHub-hosted job が起動します。公開 release ID `402850401`、tag とソース、
チェックサム、Packslip 署名、GitHub provenance を検証します。mise `2026.9.18`
で通常の署名検証を有効にしたまま公開版を正確なバージョン指定でインストールし、
インストール済み metadata と独立して検証した公開 metadata のバイト一致、
実行ファイルの SHA-256、ネイティブ実行時のバージョンを確認します。

本体が一時領域に新しい状態ディレクトリを作り、オフラインのバックグラウンド
モードで動作します。15 分間の待機、各 10 秒間観測する正常な再起動 10 回、
待機中の強制停止 1 回と再起動後 60 秒間の回復を観測します。起動・停止には
制限時間があります。キャンセル時は通常の停止を試み、必要なら同一性を確認した
所有プロセスだけを Linux pidfd で停止します。別の always 実行ステップでも
後片付けを試みます。処理途中で job 自体が強制終了された場合は runner の破棄が
最後の隔離境界になります。

job のリポジトリ権限は読み取り専用です。main、tag、release、配布物、OS の
自動起動設定、ネットワーク設定、既存のプロファイルは変更しません。
ノードの登録や外部 relay の選択も行いません。

## レポートと範囲

アップロードする JSON は release・ソース・実行ファイルの同一性と集計値を
含みます。対象は RSS、カーネルが記録した RSS 最大値、descriptor・thread 数、
生存状態、通常ファイル数、論理バイト数、割り当て済みファイルブロック、
バックグラウンドログのサイズです。各稼働区間で開始値・観測最大値・終了値・
経過時間を記録します。再起動をまたぐディスク集計は fixture 終了まで保持します。
`outgoing` は `state` の内数なので、二重に足し合わせないでください。

アップロードするのは選択した集計 JSON だけです。非公開の状態、コマンド出力、
ファイル名、一時領域のパス、ログ本文、アクセスコード、鍵、環境変数は含めません。
測定が不完全な場合は失敗として扱い、それまでの集計結果を残します。
後片付けの成否も別に記録します。

- RSS は本体 1 プロセスの常駐メモリで、Go の使用中 heap とは異なります。
  1 秒間隔では短いピークを見落とす可能性があり、15 分間で長期リークの不存在は
  証明できません
- 割り当て済み通常ファイルのバイト数には filesystem journal、ディレクトリの
  metadata、削除後もプロセスが開いているファイルは含みません
- バックグラウンドの `startup.log` はソース上 1 MiB が上限で、バックアップログは
  作りません。静かな待機だけでは巻き戻し処理を検証できません。フォアグラウンドや
  OS 管理のログはこの観測の対象外です
- クラッシュで残った送信 payload は意図的に保持し、staging 容量へ計上します。
  待機中のクラッシュでは転送途中の後片付けを検証できません
- 通信量は明示的に `null` / `not_measured` とします。アプリケーションの状態で
  オフラインを確認しますが、packet capture や通信ゼロの証明ではありません
- 結果は公開済み Linux amd64 実行ファイルと、この範囲を限定した fixture のものです。
  他のネイティブ環境では、別にインストール済みバイナリの受入検証結果があります

後日 relay の通信量を測定する場合は、ソースからビルドした relay 専用テストと
明記する必要があります。隔離した統合テストは OS UDP transport を除外し、
合成 peer と証明書を固定した loopback relay を使います。公開版そのものや
実機・WAN の測定とは区別します。
