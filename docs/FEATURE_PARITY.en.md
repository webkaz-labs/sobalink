# Feature parity and acceptance

[日本語](FEATURE_PARITY.ja.md) · [All guides](README.en.md) · [Verification evidence](VERIFICATION.en.md)

**Alpha.2 has passed its automated release gates; full feature-by-feature physical acceptance remains open.** The historical matrix baseline is [sobalink `0.3.0-alpha.2`](https://github.com/webkaz-labs/sobalink/releases/tag/v0.3.0-alpha.2), source `00cc6a99809df77bf1754936ea7bf5ca4c5d0741`. This matrix tracks capabilities from the earlier [legacy `v0.2.0-alpha.2`](https://github.com/webkaz-labs/sobalink/releases/tag/v0.2.0-alpha.2), source `0b0a13c4edd2924de149650152445507cc709da7`. Stable F01–F56 IDs distinguish functionality from old command/config spelling. Human CLI workflows, reviewed discovery, client helpers and opt-in startup/private proxy settings are included in the published sobalink baseline. Prepared-route recovery from PR #8 was already included in alpha.4. The current release is alpha.5; see [current exact-source evidence](VERIFICATION.en.md). The F01–F56 rows below preserve the alpha.2 checkpoint, including then-pending follow-ups; they are not the current release-status table.

“Implemented” identifies a source path. Alpha.2's [exact-source CI](https://github.com/webkaz-labs/sobalink/actions/runs/37177788934) passed its four native jobs, actual Go-backed browser suite and manifest check; [release run 37178488713](https://github.com/webkaz-labs/sobalink/actions/runs/37178488713) passed all 15 jobs, including signatures/provenance, public retrieval and four-target mise installation. These aggregate results do not prove every scenario in F01–F56. Real enrollment, phone QR, native IME/terminal behavior, ordinary-user Windows processes, physical applications and OS sign-in/suspend remain separately gated. “Alpha.2 CI/browser passed” below refers to that source and suite, not the current PR or full physical acceptance.
