# ローカル転送設定リソース: ソースビルドの確認機能

[English](RESOURCE_SETTINGS.en.md) · [使い方](GENERIC.ja.md)

このソースには、転送の受付制限2項目についてローカル一覧・内容確認・変更案の確認を行う機能があります。新しい公開版の案内ではありません。この段階では適用、永続的な操作結果、遠隔管理は未実装です。版番号や公開時期の確約もありません。

## 内容と変更案の確認

ローカルの本体を起動し、別の端末ウィンドウで同じプロファイルを指定します。

```sh
soba resource list
soba resource inspect --id RESOURCE_ID
soba resource preview --id RESOURCE_ID --concurrent-files 4 --concurrent-per-peer 2
soba resource preview --id RESOURCE_ID --concurrent-files default --concurrent-per-peer default
```

`RESOURCE_ID` は `list` が返した正確な不透明 ID に置き換えてください。変更案には両項目が必要です。`default` または正の有限整数を使い、`unlimited`、ゼロ、負数、対応する JSON 整数の範囲外は拒否します。提供側でも容量設定全体の変更案を検査します。確認だけでは設定を変更せず、転送も開始しません。将来の適用機能で制限を下げる場合も、新規受付に反映し、進行中の転送を中止するものではありません。

3コマンドとも言語によらず安定した JSON を返し、明示的な `--json` も使えます。ヘルプと入力エラーは `--locale auto|ja|en` に従います。`requested` は指定した選択肢、`effective` は解決後の値です。共通オプション `--dry-run` は本体に接続せず、入力検査と要求の表示だけを行います。現在の状態の検査や正式な変更確認ではありません。共通オプション `--offline` による停止中の設定編集は非対応です。`start --offline` で起動した本体では、保存済みネットワークを開始せず確認できます。

対応操作として提示するのは `list`・`inspect`・`preview` のみです。使える適用・操作結果照会コマンドはありません。既存の認証付きローカル IPC とローカル Web の `/api/command` ディスパッチャーを使います。Web UI の操作部品、相手向けの管理接続口、遠隔管理の許可、探索の広告は追加しません。固定の `local-control` アクターはローカルの権限範囲を表し、個人を識別するものではありません。

## ID・変更確認・互換性の契約

- 対象は `transfer-admission-settings` 型の1リソースです。権限主体と提供側はローカル範囲で、不透明な永続 ID を持ちます。ID は端末名・パス・アドレス・相手の識別子ではありません。非公開の保存ディレクトリー全体を複製すると、このローカル ID も複製されます。遠隔で複製を解決する機能はありません。
- 対象項目は `transferConcurrentFiles` と `transferConcurrentPerPeer` だけです。正本は既存の容量設定で、無関係な設定と既存のプロファイル・容量ファイル形式を維持します。
- 変更確認は現在の設定・プロファイル、正確な指定値、現在のプロセスの権限状態の revision に結び付きます。既存のローカル権限状態への書込みは、変更後に元へ戻した場合も確認を無効にします。再起動後は確認し直します。revision は不透明な確認トークンで、過去の完了証明ではありません。
- ID は別の上限付き非公開ファイルに保存します。所有権を確保した起動処理が検査と原子的な再保存を完了してから、使えるリソースとして公開します。破損・非対応・永続化不確実な状態では ID を勝手に作り直さず、この新機能だけを無効にします。既存機能は維持します。旧版が追加ファイルを理解する必要はありません。リソース対応版を旧版へ戻した際に後続の記録を読めなければ、リソース機能だけが利用不可になり得ます。既存の設定ファイル形式は変更しません。
- 記述子と確認結果には非公開パス・相手一覧・通信の識別子・プロファイル全体を含めません。固定のローカル権限範囲は個人の利用者を特定するものではありません。ペアリングから管理権限を推定しません。

変更案の確認成功は、設定保存・稼働中の転送への反映・永続操作の復旧・相手側での適用・実端末の受入完了を意味しません。それらはこの段階の対象外です。[開発原則](DEVELOPMENT_PRINCIPLES.ja.md)と[安全性の境界](../SECURITY.md)も参照してください。
